## Зачем SYC-AI

Вы платите за Claude **и** ChatGPT, но каждый живёт в своём терминале, со своей памятью, на одной машине. Когда одна подписка упирается в лимит посреди задачи, работа останавливается. С телефона сессию не начать, и вы не знаете, когда агент ждёт вашего подтверждения.

**SYC-AI собирает всё в одном месте.** Подключите компьютер один раз и откройте **SYC-AI — All in One**: одну сессию, где Claude планирует, Codex строит, а короткие вопросы уходят лёгкой модели — в одной папке проекта и с одной памятью. Когда подписка упирается в лимит, следующий движок продолжает то же сообщение. Ваши логины и файлы остаются на вашем компьютере.

## Начало работы

Один аккаунт, четыре способа входа. Зарегистрируйтесь на **[app.syc-ai.com](https://app.syc-ai.com/login?lang=ru)** с адресом Gmail, именем пользователя и паролем.

| | Где | Как |
|---|---|---|
| 🌐 | **Веб** | Откройте **[app.syc-ai.com](https://app.syc-ai.com/login?lang=ru)** в любом браузере. |
| 📱 | **Android** | **[Скачайте приложение SYC-AI](https://syc-ai.com/download/syc-ai.apk)** (APK) — панель на телефоне и канал для оповещений. |
| 🐧 | **Linux / macOS** | `curl -fsSL https://syc-ai.com/node/ru/install.sh \| bash` |
| 🪟 | **Windows** | `irm https://syc-ai.com/node/ru/install.ps1 \| iex` — а в Chrome или Edge пункт «Установить SYC-AI» делает панель приложением. |

Затем откройте **Профессиональные аккаунты**, нажмите **Установить** у Claude или Codex и один раз **войдите** в своём браузере. Готово.

> Это русские ссылки установки: установщик спросит «English или Русский?». Если Node.js нет, он установится; при запуске от root на Linux создаётся отдельный пользователь `syc-node`. Удалить всё можно в любой момент: `syc-node uninstall`.

## Как это работает

- Ваш компьютер сам подключается **к** syc-ai.com. На вашей машине не открывается ни один порт, сервер не нужен.
- Панель просит SYC Node запустить установленный ИИ-CLI. CLI общается с Anthropic или OpenAI напрямую, под вашим аккаунтом.
- Ваши сообщения и ответы агентов проходят через панель и сохраняются в истории сессии, чтобы продолжить на другом устройстве.

## Где хранятся ваши данные

| На вашем компьютере | На syc-ai.com | Под вашим контролем |
|---|---|---|
| Входы в Claude и OpenAI (их хранят CLI) | Аккаунт SYC-AI (почта, имя, хеш пароля) | `syc-node pause` — панель не использует устройство до возобновления |
| Ваши файлы и проекты | История сессий, чтобы продолжать где угодно | `syc-node log` — все запросы панели к устройству |
| Команды, которые выполняют агенты | Названия устройств, оповещения, обращения | `syc-node uninstall` · выгрузка данных из профиля |

Подробнее: [конфиденциальность](https://syc-ai.com/privacy) · [условия](https://syc-ai.com/terms).

## SYC Node — агент на вашем устройстве

SYC Node — один файл без зависимостей ([`node-agent/syc-node.mjs`](node-agent/syc-node.mjs)). Он запускает **только** ИИ-CLI (`claude`, `codex`, `gemini`, `cursor-agent`, `kimi`, `qwen`), установку именно этих пакетов через npm и официальный установщик Cursor, **отклоняя любые другие программы**; читает и пишет **только внутри `~/.syc-node`**; отбрасывает переменные окружения, которые могли бы перенаправить CLI на другой сервер или подгрузить код; **записывает каждый запрос** в `~/.syc-node/activity.log`; обновляется **только** сборками, подписанными ключом релизов SYC.

## Вопросы

**Это бесплатно?** SYC-AI (Main) бесплатна на время запуска. Платные редакции появятся позже, цена будет показана заранее.

**Нужен ли сервер?** Нет. Достаточно своего ноутбука или ПК; сервер тоже подойдёт.

**Мой код отправляется вам?** Файлы остаются на вашем компьютере. Переписка — ваши сообщения и ответы, которые могут цитировать части файлов, — проходит через syc-ai.com и хранится в истории сессии.

**Вы связаны с Anthropic, OpenAI или Google?** Нет. SYC-AI — независимый продукт; вы работаете со своими аккаунтами по правилам каждого сервиса.
