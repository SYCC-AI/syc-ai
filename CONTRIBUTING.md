# Contributing

Thanks for your interest in SYC-AI.

This is a source-available project under the Business Source License 1.1. You are
welcome to open issues for bugs and suggestions.

## Issues

- Search existing issues first.
- Include your OS, Node.js version, build target and clear reproduction steps.
- For security reports, do **not** open a public issue — see [SECURITY.md](SECURITY.md).

## Pull requests

- Keep changes focused and described.
- By submitting a contribution you agree it may be distributed under the project's
  license.
- Do not include secrets, credentials, real server addresses, or third-party
  binaries in a contribution.

## Not accepted

- Changes that remove the license, the attribution, or the SYC / SYC-AI brand.
- Rebranding or "white-label" forks (see the license terms).
