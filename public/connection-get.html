3 · Linux

Installs SYC Node, so this panel runs your Claude and Codex accounts on that computer. Run it in a terminal:

curl -fsSL https://syc-ai.com/node/install.sh | bash

4 · Desktop (Windows / macOS)

Open app.syc-ai.com in Chrome or Edge and choose “Install SYC-AI” (the install icon in the address bar). It opens in its own window with its own icon.

To run your accounts on a Windows computer, also install SYC Node. Run it in PowerShell:

irm https://syc-ai.com/node/install.ps1 | iex
