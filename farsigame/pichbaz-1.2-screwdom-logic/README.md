# PichBaz 1.2.0 — Screwdom logic for levels 1-10

Delivery folder of the cloud session FarsiGamecloud2 (2026-10-08) for the private game project PichBaz (Godot 4.7.2).
It carries no game source of its own: the server applies `bundle/pichbaz-sl-1.2.0.tar.gz` with `Tools/sl_apply.sh`.

- `bundle/pichbaz-sl-1.2.0.tar.gz` — the changed project files (ten cube models, levels 1-10, generator, tests, docs).
- `Tools/sl_apply.sh` — backup, extract, import, tests, APK export 1.2.0 (code 10), upload, publish, commit.
- `docs/` — the design note (Persian) and the owner's phone checklist.
