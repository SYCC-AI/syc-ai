## البدء

1. **سجّل** في **[app.syc-ai.com](https://app.syc-ai.com/login?lang=ar)** عبر Google أو GitHub، أو بعنوان Gmail وكلمة مرور. حسابات SYC-AI مبنية على Gmail: لاستخدام GitHub يجب أن يحتوي حسابك على GitHub على عنوان Gmail موثَّق.
2. **احصل على التطبيق:**

| | أين | كيف |
|---|---|---|
| 📱 | **Android** | **[نزّل syc-ai.apk](https://syc-ai.com/download/syc-ai.apk)** (ليس على Google Play بعد؛ يثبّته Android بعد تأكيدك). افتحه وسجّل الدخول. عند أول تشغيل يثبّت Claude Code وCodex على الهاتف — بضع دقائق — ويربط الهاتف بحسابك من تلقاء نفسه. |
| 🪟 | **Windows (x64)** | **[نزّل SYC-AI-Setup.exe](https://syc-ai.com/download/SYC-AI-Setup.exe)** وشغّله. لا يحتاج صلاحيات المسؤول. يعرض رمزًا قصيرًا ورابطًا: افتح الرابط حيث سجّلت الدخول إلى SYC-AI — على الحاسوب نفسه أو على هاتفك — واضغط **ربط هذا الجهاز** خلال 10 دقائق. |
| 🌐 | **الويب** | يعرض **[app.syc-ai.com](https://app.syc-ai.com/login?lang=ar)** في أي متصفح ملفك الشخصي وخطتك وحالة أجهزتك. لربط Claude وCodex تحتاج إلى تطبيق Android أو Windows. |

3. **سجّل الدخول إلى Claude وCodex.** في **الحسابات الاحترافية** اضغط **تسجيل الدخول** على كل محرك وسجّل الدخول مرة واحدة في متصفحك. ثم افتح **SYC-AI — All in One** وابدأ العمل.

> ملف Setup.exe لـ Windows غير موقّع رقميًا بعد، لذا قد يطلب Windows SmartScreen تأكيدك (**مزيد من المعلومات ← التشغيل على أي حال**). يمكنك إزالته في أي وقت من **التطبيقات والميزات**.

## كيف يعمل

- يتصل جهازك **صادرًا** بـ syc-ai.com. لا يُفتح أي منفذ عليه ولا حاجة إلى خادم ([اقرأ شيفرة الوكيل](node-agent/syc-node.mjs)).
- تطلب اللوحة من SYC Node تشغيل أداة CLI المثبّتة على جهازك. تتواصل الأداة مباشرة مع Anthropic أو OpenAI بحسابك أنت.
- تمر رسائلك وردود الوكلاء عبر اللوحة وتُحفظ في سجل جلساتك لتتابع على جهاز آخر. وهي غير مشفّرة تشفيرًا تامًّا بين الطرفين (end-to-end).

## SYC Node — الوكيل على جهازك

SYC Node ملف واحد بلا اعتماديات ([`node-agent/syc-node.mjs`](node-agent/syc-node.mjs)) موجود داخل تطبيقَي Android وWindows:

- **لا يشغّل إلا** أدوات CLI للذكاء الاصطناعي (`claude` و`codex` و`gemini` و`cursor-agent` و`kimi` و`qwen`)، وتثبيت هذه الحزم بعينها عبر npm في `~/.syc-node/npm`، ومثبّت Cursor الرسمي؛ **ويرفض أي برنامج آخر**؛
- **لا يقرأ ولا يكتب إلا داخل `~/.syc-node`**؛
- **يُسقط أي متغير بيئة** قد يعيد توجيه الأداة إلى خادم آخر أو يحمّل شيفرة مسبقًا؛
- **يتحقق من توقيع** كل ملف إعدادات لـ SYC-AI يكتبه، ويعيد الملف الذي تغيّر؛
- **يسجّل كل طلب** في `~/.syc-node/activity.log`؛
- **لا يحدّث نفسه إلا** بإصدارات موقّعة بمفتاح إصدارات SYC.

## أسئلة

**هل هو مجاني؟** SYC-AI (Main) مجاني حتى 31 ديسمبر 2026، ثم يكلّف 1.75 دولار شهريًا. تأتي الإصدارات المدفوعة لاحقًا ويظهر سعرها قبل الاختيار؛ الدفع غير متاح بعد.

**هل أحتاج إلى خادم؟** لا. يكفي هاتفك Android أو حاسوبك بنظام Windows.

**هل يجب أن أثبّت Claude Code أو Codex أولًا؟** لا. كلاهما موجود داخل تطبيق Android وتطبيق Windows. عليك فقط تسجيل الدخول مرة واحدة من اللوحة إلى حسابيك في Claude وChatGPT.

**ماذا أستطيع أن أفعل في المتصفح؟** تعرض لوحة الويب ملفك الشخصي وخطتك وترقيتها وحالة أجهزتك. أما العمل مع Claude وCodex فيحتاج إلى تطبيق Android أو Windows، لأن الوكلاء يعملون على جهازك.

**هل تُرسل شيفرتي إليكم؟** تبقى ملفاتك على جهازك. أما المحادثة — رسائلك وردود الوكلاء التي قد تقتبس أجزاء من الملفات — فتمر عبر syc-ai.com وتُحفظ في سجل جلساتك.

**ماذا يستطيع SYC Node أن يفعل على جهازي؟** فقط تشغيل أدوات CLI للذكاء الاصطناعي، وتثبيت هذه الأدوات بعينها عبر npm، والقراءة والكتابة داخل `~/.syc-node`. كل ما عدا ذلك يُرفض ويُسجَّل. يمكنك إيقافه مؤقتًا أو إزالته في أي وقت. [اقرأ الشيفرة](node-agent/syc-node.mjs).

**هل يلتف SYC-AI على حدود استخدام اشتراكاتي؟** لا. يعمل كل محرك بحسابك وضمن حدوده. حين يبلغ اشتراك حدّه، يمكن لـ SYC-AI متابعة العمل نفسه بمحرك *آخر* تدفع له أيضًا (مثل Codex بعد Claude). ولا يتنقّل أبدًا بين عدة حسابات لدى المزوّد نفسه للالتفاف على الحد.

**هل توجد نسخة لـ iPhone أو Mac أو Linux؟** لا. يعمل SYC-AI على Android وWindows. وعلى أي جهاز آخر تعرض لوحة الويب ملفك الشخصي وخطتك وأجهزتك.

**هل SYC-AI تابع لـ Anthropic أو OpenAI أو Google؟** لا. SYC-AI منتج مستقل، وتستخدم حساباتك الخاصة وفق شروط كل مزوّد. Claude وCodex وGemini وCursor وKimi وQwen علامات تجارية لأصحابها.

## الأمان

الإصدارات وتحديثات SYC Node موقّعة بـ Ed25519؛ تتحقق اللوحة من الحجم ومن SHA-256 قبل كتابة أي بايت، وتطبّق التحديثات كوحدة واحدة وتتراجع عند الفشل. تستخدم الجلسات ملفات تعريف ارتباط آمنة وحماية من CSRF؛ وتُجزَّأ كلمات المرور بـ scrypt؛ ولا تُحفظ رموز الأجهزة إلا كتجزئات. أبلغ عن ثغرة بشكل خاص: [SECURITY.md](SECURITY.md).
